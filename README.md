# Video-Reel-Creator-with-Text-to-Speech-Audio:
This project is a Flask web app that creates video reels by combining uploaded images with AI-generated speech audio using ElevenLabs API, and compiles them into videos via FFmpeg for easy, automated multimedia content creation.
# Key Features:
File Upload: Users can upload multiple images via the web interface. Text Description: Users add descriptive text which is converted to audio narration. Text-to-Speech Integration: Powered by the ElevenLabs API, generating lifelike audio from text input. Automatic Video Reel Creation: Using FFmpeg, a video slideshow is created combining images and the generated audio. Background Processing: Folder monitoring and reel generation run in the background to automate video creation. Progress Tracking: Processed uploads tracked in a text file to avoid duplicate processing.
# How it Works:
Upload & Input: Users upload images and provide descriptive text through the Flask web interface. Audio Generation: The text is sent to ElevenLabs API to synthesize realistic speech audio, saved as audio.mp3. Video Slideshow Preparation: A playlist file input.txt listing uploaded images is generated for FFmpeg. Reel Creation: FFmpeg concatenates the images and audio with video filters applied for resolution and aspect ratio. Background Task: A background Python process monitors uploads folder, processes new user folders into reels, and logs completed folders.
# Tools & Technologies Used:
Python & Flask: Web server and backend logic managing file uploads and API calls. ElevenLabs API: Advanced text-to-speech service used to generate high-quality human-like audio voiceovers. FFmpeg: Command-line multimedia framework to convert images and audio into a video reel with custom video parameters. Werkzeug: Utility library used for securely handling uploaded filenames. UUID: For creating unique folder identifiers for each upload session. Subprocess: To run FFmpeg commands in backend scripts. Threading & Background Processing: For automating reel generation asynchronously without blocking the server.
# Setup Instructions:
Clone the repository. Install Python dependencies: Flask, elevenlabs client, and others (via pip). Set up your ElevenLabs API key in the config.py. Run the Flask app and open the web interface. Upload images and add descriptive text to create video reels. Background process will automatically generate audio and reel videos for each upload folder.
# Notes:
Make sure FFmpeg is installed and added to your system PATH for command-line usage. The background process needs the ffmpeg command updated with your specific input/output paths. Audio file generation depends on ElevenLabs API availability and quota.
